# MacroTrace v0.4.0 launch summary

MacroTrace v0.4.0 is the first public local-run source release.

## Shipped

- English `main` landing page and Chinese `README.zh-CN.md`
- local PowerShell setup and foreground start scripts
- privacy-clean source repository
- separate reviewed DuckDB snapshot with empty research-history tables
- 10 lanes, 31 mechanisms, 55 factors, 82 model specifications, 30 nodes, and 6 workflows
- 30 reviewed semantic reverse records plus the initial 11-report registry
- local BYOK model and official-data credential interface
- real product screenshots, animated walkthrough, architecture diagram, and reproducible verification commands

## Distribution boundary

This release is a local research application, not a hosted multi-user service. It binds to loopback by default. Users provide their own model and data-provider credentials.

## Honest limitations

The snapshot is not a real-time data subscription; vintage coverage is incomplete across sources; unavailable identification designs reduce coverage; association is not relabeled as causality.
