# Bilingual GitHub release plan

- `main`: English README as the default GitHub landing page.
- `README.zh-CN.md`: full Chinese documentation in the same commit.
- `zh-CN`: localized branch whose landing `README.md` is Chinese.
- GitHub Release title and notes: English summary followed by Chinese summary.
- Product UI: bilingual research terminology where useful, with Chinese-first explanatory copy.
- Claims, numbers, commands, screenshots, limitations, and release assets must remain consistent across languages.
