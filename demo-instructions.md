# Demo instructions

1. Run `scripts/setup_mvp.ps1`.
2. Run `scripts/start_macrotrace.ps1`.
3. Ask: `美国联邦债务扩张是否正在增加十年期收益率压力？`
4. Inspect the direct answer and identification-limit subtitle.
5. Open Research Graph and filter by routed nodes.
6. Select a model run and review Specification, Data & Variables, Results, Diagnostics, Robustness, and Provenance.
7. Open API & data sources and verify that stored credentials are masked.
8. Press `Ctrl+C` in the server terminal.

The screenshots under `docs/assets/` are real product captures. They contain no usable credentials.
