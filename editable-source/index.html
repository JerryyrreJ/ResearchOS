LAYER B

Thesis Compiler

把自然语言判断编译成可验证命题和结论资格。

  • 命题与变量
  • 证据 / 反证
  • 适用范围与限制

LAYER C

MacroTrace

运行已注册模型、诊断和稳健性检查。

  • Research Graph
  • Registered Models
  • Diagnostics & Evidence
交接：Evidence Bundle
AI 负责理解与编译；确定性程序负责执行；证据决定能说到哪里。

Template 05A · AI / Agent
06 · AI 与 Agent 分工

不是一个 Agent 包办全部，
而是五个角色沿研究契约协作

01Research Assistant理解开放问题，保留研究上下文与初始意图。输出：Research Question
02Evidence Curator整理公开来源、市场数据、内部资料与精确引用。输出：Context Pack
03Thesis Compiler拆解命题、变量、反证、限制与验证计划。输出：Validation Plan
04MacroTrace Engine注册模型、确定性执行、诊断、稳健性与失败记录。输出：Evidence Bundle
05Report Builder按结论资格生成周报、月报或专题研究出品。输出：Research Output
每个 Agent 只对自己的研究职责负责，交接物可见、失败状态可见。

Template 05B · Checks & Boundary
07 · 校验、失败状态与结论边界

系统不是让 AI 更敢说，
而是让每句话只说到证据允许的程度

OVERCLAIM · 越界

“政策变化导致风险资产上涨。”

EVIDENCE RETURN · 新证据回流

模型只提供关联性与预测性证据，因果识别条件不成立。

RECOMPILE · 重新编译

保留 Fixture / Offline Replay / Real API 模式，Partial 与 Failed 状态不被隐藏。

QUALIFIED CLAIM · 有资格表达

“在当前样本与设定下，两者呈现关联；因果关系尚不能由本次结果识别。”

失败不是异常信息，而是研究资产的一部分；边界不是免责声明，而是结论资格。
