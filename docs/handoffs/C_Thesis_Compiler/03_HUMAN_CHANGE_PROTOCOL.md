# Human Change Protocol

The human owner can change local implementation freely inside this role's boundary.

A human request must go through ICR when it changes:

- a public JSON field;
- an enum or state meaning;
- an endpoint;
- object identity or version policy;
- evidence type;
- conclusion state;
- directory ownership;
- database access boundary;
- the guaranteed Demo route.

## Codex response

1. Do not edit yet.
2. Quote the exact boundary.
3. Identify affected producer and consumers.
4. Explain concrete breakage.
5. Offer a non-breaking local alternative.
6. Draft `docs/rfcs/ICR-<number>-<slug>.md`.
7. Wait for required approval.

## Approval marker

An ICR is implementable only when its file contains:

```text
Decision: APPROVED
Approved by A: yes
Approved by B: yes
Approved by C: yes
Approved by D: yes
Contract version: <new version if required>
```
