# README visual design

- First screen: product name, one-sentence value proposition, release/test/runtime badges, bilingual link, and a real direct-answer screenshot.
- Visual rhythm: one large hero, then research graph, academic results, and provider settings.
- Color language: neutral paper background, black editorial typography, blue research-system accents, green success, amber identification limits.
- Diagrams: Mermaid for the compiler flow and runtime architecture.
- Long technical detail stays below the value proposition and inside one collapsible demo section.
